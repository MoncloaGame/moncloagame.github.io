# Moncloa Game

Juego de preguntas sobre política española para 1–4 jugadores, en un mismo móvil o en partida online por enlace.

**Jugar:** https://moncloagame.github.io/

- Seis categorías y seis quesitos.
- Prueba final en el centro del tablero para llegar a La Moncloa.
- Se puede instalar como app desde el navegador del móvil.
